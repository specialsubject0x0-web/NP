## 使用者故事
身為〔會員〕，我想要〔把商品加入購物車並調整數量〕，以便〔一次結帳多件商品〕。

## 驗收條件（Given / When / Then）
- AC1（正面）：Given 已登入 When 加入商品數量 2 Then 購物車出現該商品，小計＝單價×數量（僅供顯示）
- AC2（負面）：數量為 0、負數、100 或超過庫存 → 422／409，購物車不變（R-05）
- AC3（負面）：未登入呼叫購物車 API → 401；前端導向登入頁（R-04）
- AC4（負面）：缺少 CSRF token → 403（R-17）
