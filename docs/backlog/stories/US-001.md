## 使用者故事
身為〔訪客或會員〕，我想要〔依關鍵字、分類、價格區間搜尋並排序商品〕，以便〔快速找到想買的東西〕。

## 驗收條件（Given / When / Then）
- AC1（正面）：Given 有上架商品 When 用關鍵字「杯」搜尋 Then 只列出名稱或描述含「杯」的上架商品，並回傳總筆數（R-18）
- AC2（正面）：Given 選擇排序 price_asc Then 依價格由低到高（R-18）
- AC3（負面）：Given sort=password 或 page_size=500 When 請求 Then 回 422，不執行查詢（R-18）
- AC4（負面）：下架商品不出現在列表
