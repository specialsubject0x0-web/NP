## 驗收條件（Given / When / Then）
- AC1（正面）：WELCOME100（滿 500 折 100）在小計 600 時 → 折 100，運費 60，總計 560（R-03、R-12）
- AC2（正面）：SAVE10（9 折，最多折 200）在小計 3000 時 → 只折 200（R-12）
- AC3（負面）：過期、未開始、未達門檻、超過總次數、已用過、代碼不存在 → 422／409，並給清楚訊息（R-12）
- AC4（負面）：一次送兩張優惠碼 → 422（不可疊加，R-12）
- AC5（正面）：取消訂單後可再次使用該券（R-09）
