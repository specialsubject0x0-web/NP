## 使用者故事
身為〔會員〕，我想要〔確認金額後送出訂單〕，以便〔完成購買〕。

## 驗收條件（Given / When / Then）
- AC1（正面）：Given 購物車小計 900 When 試算 Then 運費 60、總計 960（R-03）；小計 1000 → 免運
- AC2（正面）：下單後庫存扣除、購物車清空、訂單狀態為 pending_payment，明細保存當下價格（R-06、R-07、R-08）
- AC3（負面）：最後 1 件被兩人同時下單 → 只有 1 人成功，另一人 409 `ORDER_OUT_OF_STOCK`，庫存不會變負數（R-06）
- AC4（負面）：同一 Idempotency-Key 送兩次 → 只建立一筆訂單（R-11）；缺少 Key → 400
- AC5（負面）：請求中夾帶 price、total 等欄位 → 422；金額一律由後端計算
- AC6（負面）：購物車是空的 → 409 `CART_EMPTY`
