## 使用者故事
身為〔會員〕，我想要〔查看自己的訂單並取消未付款的訂單〕，以便〔掌握購買狀態〕。

## 驗收條件（Given / When / Then）
- AC1（正面）：只列出自己的訂單，依建立時間新到舊
- AC2（負面）：讀取別人的訂單 → 404（R-13）
- AC3（正面）：取消待付款訂單 → cancelled，庫存回補、優惠券次數歸還（R-09）
- AC4（負面）：取消已付款訂單 → 409 `ORDER_INVALID_TRANSITION`（R-08）
