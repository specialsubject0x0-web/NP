## 使用者故事
身為〔訪客或會員〕，我想要〔查看商品的價格、庫存與說明〕，以便〔決定要不要買〕。

## 驗收條件（Given / When / Then）
- AC1（正面）：Given 商品上架 When 開啟詳情 Then 顯示名稱、價格（TWD 整數）、庫存、說明（R-01）
- AC2（錯誤）：id 不存在、為 0 或負數、或商品已下架 → 404 `PRODUCT_NOT_FOUND`，不洩露內部細節
