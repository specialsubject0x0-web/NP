## 1. 目標
讓會員能在網站上找到商品、放進購物車、結帳並付款，並能查詢自己的訂單。這是購物網站最核心的價值。

## 2. 範圍
**包含**：商品列表（搜尋、分類篩選、價格區間、排序、分頁）、商品詳情、購物車、收件地址、結帳試算、建立訂單、模擬付款、訂單查詢、取消待付款訂單。

**不包含**：商品規格（尺寸／顏色）、退貨退款、物流追蹤、未付款逾時自動取消、寄信通知、多幣別。

## 3. Story 清單
- US-001 瀏覽與搜尋商品
- US-002 查看商品詳情
- US-003 管理購物車
- US-004 管理收件地址
- US-005 結帳並建立訂單
- US-006 模擬付款
- US-007 查詢與取消我的訂單

## 4. 成功指標（可量測）
- E2E 主流程（找商品 → 加入購物車 → 結帳 → 付款 → 查訂單）自動測試通過
- 超賣、重複下單、重複付款回呼的負面測試全部通過
