# 程式碼導覽（給看不熟程式的人）

> 由開發角色在**每個 Task 完成時**更新自己負責的部分。目的：讓學生與老師看得懂「這個檔案是做什麼的、怎麼改」。
> 內容用白話繁體中文，避免艱深術語；第一次出現的術語要簡單解釋。

## 名詞小辭典
| 名詞 | 白話說明 |
|---|---|
| API | 前端向後端要資料或送資料的「窗口」 |
| Mock | 假的後端，讓前端不需真的後端也能跑 |
| 元件（Component） | 畫面上可重複使用的一小塊，例如商品卡片 |
