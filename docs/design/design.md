# 設計文件（ui-ux-designer）

## 頁面流程
```
首頁 ─▶ 商品列表（搜尋／分類／價格／排序／分頁）─▶ 商品詳情 ─▶ 加入購物車
                                                       │（未登入 → 登入頁 → 回原頁）
購物車 ─▶ 結帳（選地址、輸入優惠碼、後端試算）─▶ 送出訂單 ─▶ 訂單詳情 ─▶ 模擬付款
我的訂單 ─▶ 訂單詳情（付款／取消）
後台（管理員）：商品管理（新增、改價、庫存、上下架）、訂單管理（出貨、完成、取消）
```

## 版面
- 上方：頁首（店名、標語、搜尋、購物車數量、登入狀態）；下方：頁尾（文案在 `content/footer.json`）
- 商品卡片格線：每列數量由 `site.config.ts` 的 `productsPerRow` 決定，窄螢幕自動減少
- 最大寬度 1120px，置中

## 設計系統（`frontend/src/theme/tokens.css`）
| 類別 | 變數 | 預設 |
|---|---|---|
| 主色 | `--color-primary` | 深青綠 #0f766e |
| 強調色 | `--color-accent` | 琥珀 #b45309 |
| 文字／背景 | `--color-text`、`--color-bg`、`--color-surface` | 深灰／米白／白 |
| 字型 | `--font-family` | 系統字型（不載入外部字型） |
| 間距 | `--space-1`～`--space-6` | 4px 倍數 |
| 圓角 | `--radius` | 10px |

## 無障礙
- 文字與背景對比 ≥ 4.5:1（主色上的白字 #0f766e/#fff ≈ 5.4:1）
- 所有圖片有 `alt`；表單欄位都有 `<label>`；錯誤訊息用 `role="alert"`
- 可用鍵盤完成主流程；焦點外框不移除
- 商品圖為自製 SVG 色塊（假設 A-11），不使用未授權圖片
